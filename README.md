# VMEmulator —— Nand2Tetris 项目7 虚拟机翻译器（C++实现）

## 第一阶段 · 核心翻译引擎

================================================================================

## 项目简介

VMEmulator 是一个将栈式虚拟机指令（.vm）翻译为 Hack 汇编代码（.asm）的编译器前端工具。
本项目实现了《计算机系统要素》（Nand2Tetris）课程 Project 7 的第一阶段，
能够处理算术运算、逻辑运算、内存段访问等核心指令。

采用 C++17 标准编写，零外部依赖，架构清晰，运行高效。

================================================================================

## 功能特性

+ 算术运算：add、sub、neg
+ 逻辑运算：and、or、not
+ 比较指令：eq、gt、lt
+ 内存段访问：push、pop
+ 支持的段：local、argument、this、that、pointer、temp、static、constant

================================================================================

## 架构设计

源文件 (.vm)  ->  Parser (词法分析)  ->  CodeWriter (汇编代码生成)  -> 目标文件 (.asm)

核心模块说明：

[Parser]      读取 .vm 文件，跳过注释与空行，识别指令类型，提取操作数
[CodeWriter]  根据指令类型生成 Hack 汇编代码，管理栈指针 SP 及内存段映射
[CommandType] 枚举指令类型：算术指令、压栈、弹栈等

================================================================================

## 内存段映射表

VM 段         | Hack 映射      | 地址计算方式
--------------|----------------|------------------
local         | LCL            | LCL + index
argument      | ARG            | ARG + index
this          | THIS           | THIS + index
that          | THAT           | THAT + index
pointer       | R3 - R4        | 基址 3 或 4 + index
temp          | R5 - R12       | 基址 5 + index
static        | 文件名.n       | 静态变量区（16 - 255）
constant      | 立即数         | 直接使用常量值

================================================================================

## 编译与运行

编译要求：
- C++17 兼容编译器（GCC、Clang、MSVC）
- 支持 <filesystem> 标准库

编译命令：
g++ -std=c++17 -O2 VMEmulator.cpp -o VMEmulator

使用方法：
./VMEmulator <源文件.vm>

示例：
./VMEmulator BasicTest.vm

输出文件：BasicTest.asm
